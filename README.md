# Harishma M · Interactive Portfolio

An interactive, no-scroll portfolio built with plain HTML, CSS and JavaScript. No frameworks, no libraries.

**Live site:** https://officialmail2hari-hash.github.io/Portfolio/

## About
I'm a B.Sc Data Science student at The Standard Fireworks College for Women (CGPA 8.9), open to internships and full-time roles.

## Features
- **3D cube mode:** each section lives on a face of a cube. Drag to spin it, click a face to open it.
- **Game world mode:** fly a rocket (arrow keys or tap) between planets that open each section.
- **Orbiting skills** and flip-card **papers** with copy-able BibTeX.
- **Generated sound:** ambient audio made live with the Web Audio API (opt-in at the entry gate).
- **Achievements** and a hidden terminal Easter egg.
- **Contact form** that delivers to my inbox (via Web3Forms).
- **Classic view** (`classic.html`) for a normal scrolling page.
- Fully responsive, from phones to desktops.

## Run locally
Open `index.html` in a browser, or from the folder run `python -m http.server` and visit http://localhost:8000.

## Edit the content
All text (about, skills, projects, papers, education) is at the top of `world.js`. To enable the contact form, paste a free [Web3Forms](https://web3forms.com) key into `FORM_KEY`.
