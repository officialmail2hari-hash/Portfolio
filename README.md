# My Portfolio

A static, interactive portfolio: dark/light theme, typing intro, animated skill bars, searchable and filterable projects.

## Customize
1. `index.html` – replace "Your Name", about text, education, skills, and social links.
2. `script.js` – edit the `projects` and `roles` arrays at the top.
3. Add your `resume.pdf` to the same folder (or remove the button).
4. In `script.js`, change `you@example.com` in the contact form.

## Deploy on GitHub Pages
1. Create a new repository named `your-username.github.io` (replace with your GitHub username), set to **Public**.
2. Upload `index.html`, `style.css`, `script.js`, `README.md` (and `resume.pdf`).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://your-username.github.io`.

To preview locally, just open `index.html` in a browser.
